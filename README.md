# 票据管家

票据管家是一款面向 Windows 的本地发票管理工具，适合学校科研、竞赛、实验室和个人项目报销场景。它将发票 PDF、项目归档、报销状态、文件命名和 Excel 导出整合在一个离线桌面应用中。

## 功能

- 批量导入 PDF 发票，一键扫描“我的发票”目录。
- 自动提取发票号码、开票日期、商品名称、价税合计、税额和销售方信息。
- 自动建议报销类目，支持手动修改商品、金额、日期、类目、状态、标签和备注。
- 无法完整解析的票据标记为“待人工补充”，显示缺失字段并支持重新解析。
- 根据文件指纹、路径和发票号码检测重复发票。
- 创建、编辑、删除和归档报销项目。
- 同一发票可关联多个项目，并设置主项目。
- 项目内上传或从“我的发票”选择已有发票，自动复制项目副本。
- 项目统计显示录入、已报销、报销中、未报销和不能报销金额。
- 支持项目 Excel、全部发票 Excel 和按项目生成副本 Sheet。
- 支持绿色、蓝色、橙色、粉色主题及对应浅色/深色模式。

## 文件结构

```text
我的发票/
├─ 所有发票/          所有发票的主文件
├─ 项目名称 A/        项目 PDF 副本和 Excel
└─ 项目名称 B/
```

主文件命名格式：

```text
项目名-001-19.90-商品名称-未报销.pdf
无项目-001-金额-商品名称-状态.pdf
已报销项目-001-金额-商品名称-已报销.pdf
```

一致性校验会检查并修复主文件、项目副本、项目名称、序号和报销状态之间的命名关系。

## 环境要求

- Windows 10 或 Windows 11
- Node.js 20 或更高版本，推荐 Node.js 24
- npm 10 或更高版本

应用使用 Node.js 原生 SQLite 接口，不需要单独安装 SQLite 服务。

## 开发运行

```powershell
npm install
npm run dev
```

## 构建和打包

```powershell
npm run build
npm run dist
```

Windows 安装包输出到 `发布产物/release/`，安装程序会创建桌面和开始菜单快捷方式。免安装版本位于 `发布产物/release/win-unpacked/`。

## 测试

```powershell
npm test
```

测试覆盖金额精度和 Windows 非法文件名字符清理。建议在真实票据上验证 PDF 解析、重复导入、项目归档恢复、副本一致性和 Excel 打开效果。

## 隐私和数据

- 发票 PDF 默认只保存在本机。
- 首版不使用云端 OCR，不上传票据信息。
- SQLite 数据库位于 Electron 用户数据目录，文件名为 `invoices.sqlite`。
- `我的发票/`、`发布产物/` 和数据库文件已加入 `.gitignore`。

首版优先支持带文本层的电子发票 PDF。扫描图片型 PDF 无法提取文字时会进入“待人工补充”状态。金额默认采用票面“价税合计（小写）”，保留两位小数。
